# Símbolos
É um atalho (**Win + Alt + .**) simples pra digitar símbolos matemáticos, letras gregas, e pra converter texto selecionado em MAIÚSCULO ou minúsculo.

## Como usar
1. Baixe o `.exe` na aba **Releases** (lado direito da página do GitHub).
2. Execute o arquivo.
3. Aperte **Win + Alt + .** pra abrir o menu.
4. Clique no que quiser.
5. Pra fechar o programa, clique com o botão direito no ícone dele na área de notificação (canto direito da barra de tarefas, pode estar escondido atrás da setinha **^**) e escolha **Exit**.

## Dica: Para fazer Simbolos abrir automáticamente junto com o Windows
1. Aperte **Win + R**, digite `shell:startup` e dê Enter.
2. Mova o `.exe` ou um atalho para ele na pasta que abriu.

## Quer mexer no código?
Simbolos foi feito em AutoHotkey **v2.0**. 
O código-fonte está no arquivo `Simbolos.ahk`. Instale o [AutoHotkey](https://www.autohotkey.com) e abra o arquivo.
